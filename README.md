# Cosmo IA Desktop — Instaladores Oficiales

Software asistente de intervención psicosocial, Trabajo Social, Psicología y Peritaje Judicial Forense para Chile, desarrollado por **Rakin IA / Fundación Rakiduam** ([rakinia.com](https://rakinia.com)).

## Descarga directa
Descarga el instalador correspondiente a tu sistema operativo desde la sección [**Releases**](https://github.com/danoriveravk-wq/cosmo-ia-releases/releases/latest):

- **Windows 10 y 11 (64-bit):** `Cosmo-RakinIA-Setup.exe`
- **macOS Apple Silicon (M1 / M2 / M3 / M4):** `Cosmo-RakinIA-macOS-AppleSilicon-arm64.dmg`
- **macOS Intel (x64):** `Cosmo-RakinIA-macOS-Intel-x64.dmg`
- **Linux Fedora / RHEL:** `cosmo-rakinia-*.x86_64.rpm`
- **Linux Portable (x64):** `Cosmo-RakinIA-Linux-x64.tar.gz`
